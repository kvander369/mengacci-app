# Mengacci $$

The app page for the Mengacci $$ at Country Club of Waterbury, served by GitHub Pages.
Open it on a phone and add it to the home screen; it works with no signal.

This repo holds only the page. Rules, design and tests live in the private working
repo; this copy is written by its deploy step and not edited by hand. No names, no
scores and no credentials are ever committed here.
